# Watchpost {{VERSION}}

Watchpost {{VERSION}} is a {{RELEASE_KIND}}.

## What this release is

- One self-hosted Go executable with an embedded dashboard and SQLite storage.
- Posts, collection, checks, rules and alerts, incidents, notifications,
  actions, audit, the evidence-grounded agent, agent pairing and retention.
- Checksum-verified release archives (and platform executables) for Linux,
  macOS and Windows on amd64 and arm64, plus `SHA256SUMS`.

## Operator responsibilities

- Back up before upgrading.
- Read the known limitations before relying on Watchpost in production.
- Watchpost is a public preview for evaluation and early self-hosting; it is
  not claimed to be production-proven or battle-proven.

## Installation

- https://watchpost.cv/install.sh (per-user)
- https://watchpost.cv/download.sh (download the archive)
- https://watchpost.cv/update.sh (upgrade an existing install)
