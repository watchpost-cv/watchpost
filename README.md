# Watchpost

Watchpost is a planned open-source, web-based monitoring and operations
platform with an evidence-grounded agent built in from the beginning.

The project is currently in product definition. Read [HANDOVER.md](HANDOVER.md)
for its boundaries and engineering principles, then [PLAN.md](PLAN.md) for the
ordered implementation programme.

Public website source lives in the sibling `watchpost-ops.github.io`
repository.
