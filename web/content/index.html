Host monitoring

Watchpost Agent, installed before pairing

  1. Install the Watchpost Agent on the machine (its local interface binds to loopback; the CLI is equivalent).
  2. From the agent, enter this Watchpost URL and request pairing. Both sides show the same three-word phrase.
  3. Match the phrase and approve it here. The agent collects its one-time credential and begins delivering CPU, memory, disk, load and uptime outbound.

An unpaired agent is a valid quiet state. Archive, delete, revoke, reset and uninstall remain distinct operations.
